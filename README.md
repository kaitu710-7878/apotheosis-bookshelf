## English

**Apotheosis Bookshelf** is a Minecraft 1.20.1 (Forge) addon for **Apotheosis** that adds configurable enchanting bookshelves, Treasure/Anvil bookshelves, and Primal crafting materials.

### Features
- **Configurable Bookshelves**:
  - **Eterna Bookshelf**: Sets Eterna contribution from `1` to `50` via right-click GUI (Max Eterna cap: `50`).
  - **Quanta Bookshelf**: Sets Quanta contribution from `1` to `100` via right-click GUI.
  - **Arcana Bookshelf**: Sets Arcana contribution from `1` to `100` via right-click GUI.
- **Special Bookshelves**:
  - **Treasure Bookshelf**: Enables treasure enchantments on the Enchanting Table while blocking curses (configurable).
  - **Anvil Bookshelf**: Enables all anvil-applicable enchantments on the Enchanting Table while blocking curses (configurable).
- **Primal Materials**:
  - **Primal End Crystal**: Obtained by right-clicking the Ender Dragon with an End Crystal.
  - **Primal Nether Star**: Obtained by right-clicking the Wither with a Nether Star.
- **Recipes**:
  - **Eterna Bookshelf**: 6 Bookshelves + 2 Mythic Rarity Materials (`apotheosis:mythic_material`) + 1 Bottle o' Enchanting.
  - **Conversion Loop**: Eterna Bookshelf → Quanta Bookshelf → Arcana Bookshelf → Eterna Bookshelf.
  - **Library of Alexandria (`apotheosis:ender_library`)**: Ender Chest + Eterna Bookshelf + Quanta Bookshelf + Arcana Bookshelf.
  - **Treasure Bookshelf**: Quanta Bookshelf + Primal Nether Star.
  - **Anvil Bookshelf**: Treasure Bookshelf + Primal End Crystal.

### Requirements
- Minecraft 1.20.1
- Minecraft Forge 47.4.0+
- Apotheosis (1.20.1)

<a name="japanese"></a>
## 日本語

**Apotheosis Bookshelf** は、Minecraft 1.20.1 (Forge) 向けの **Apotheosis** アドオンMODです。数値を指定できる本棚や、お宝・金床本棚、原初のレシピ素材を追加します。

### 主な特徴
- **パラメーター指定本棚**:
  - **エテルナ本棚**: 右クリックGUIでエテルナ値を `1`〜`50` に設定可能（上限 `50`）。
  - **クアンタ本棚**: 右クリックGUIでクアンタ値を `1`〜`100` に設定可能。
  - **アルカナ本棚**: 右クリックGUIでアルカナ値を `1`〜`100` に設定可能。
- **特殊本棚**:
  - **お宝本棚**: エンチャントテーブルでお宝エンチャントも付与可能にする（呪いはつかない／コンフィグで切替可）。
  - **金床本棚**: エンチャントテーブルで金床（鉄床）で付与可能なエンチャントすべてを付与可能にする（呪いはつかない／コンフィグで切替可）。
- **原初の素材**:
  - **原初のエンドクリスタル**: エンドクリスタルをエンダードラゴンに右クリックすることで入手。
  - **原初のネザースター**: ネザースターをウィザーに右クリックすることで入手。
- **レシピ**:
  - **エテルナ本棚**: 本棚×6、ミシックのレアリティ素材 (`apotheosis:mythic_material`)×2、エンチャントの瓶×1。
  - **変換ループ**: エテルナ本棚 → クアンタ本棚 → アルカナ本棚 → エテルナ本棚。
  - **アレクサンドリア書庫 (`apotheosis:ender_library`)**: エンダーチェスト + エテルナ本棚 + クアンタ本棚 + アルカナ本棚。
  - **お宝本棚**: クアンタ本棚 + 原初のネザースター。
  - **金床本棚**: お宝本棚 + 原初のエンドクリスタル。

### 必要環境
- Minecraft 1.20.1
- Minecraft Forge 47.4.0 以降
- Apotheosis (1.20.1)
